# SZAS STUDIO

Herramienta web para preparar imágenes para el flujo creativo/DTF de SZAS.

## V1 incluida
- Drag & drop / selector de archivos
- JPG, PNG y WEBP
- Procesamiento local en el navegador
- Brillo, contraste, saturación y nitidez
- Escala de grises
- Blanco/negro
- Invertir
- Semitono configurable
- Zoom y ajuste a pantalla
- Exportación PNG
- Diseño responsive

## Publicar en GitHub Pages
1. Crea un repositorio, por ejemplo `szas-studio`.
2. Sube todos los archivos manteniendo las carpetas.
3. Ve a **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona `main` y `/ (root)`.
6. Guarda.

La versión actual no necesita servidor ni API para las funciones incluidas.
