# SZAS STUDIO V1.5

Herramienta web local para preparar imágenes para diseño y DTF.

Incluye:
- Importación JPG/PNG/WEBP
- Ampliación 4x
- Eliminación automática de fondo simple
- Recorte al contenido
- Calado alpha
- Escala de grises, B/N, invertir
- Brillo, contraste, saturación y nitidez
- Semitono DTF con presets, densidad y patrones
- Preparación de tamaño de impresión en cm/DPI
- Separación RGB básica
- Vectorización SVG raster-to-vector por bloques
- Comparación con original
- Exportación PNG y SVG

Nota: "Quitar fondo" en esta V1.5 usa detección por color de fondo; no es todavía una IA de segmentación avanzada. "Vectorizar" crea un SVG de alto contraste por bloques; se mejorará con trazado real en una siguiente versión.
